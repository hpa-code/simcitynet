# Citation

If you use `simcitynet` in your research, please cite the paper:

> Caliskan, C., Iskakov, A., Li, Y., McCollum, B., & Ren, Y. (2025). *SimCityNet: Quantifying
> Geo-Cultural Bias in AI-Generated Urban Videos through Interpretable Scene Embeddings.*
> SSRN Electronic Journal. <https://doi.org/10.2139/ssrn.5369073>

```bibtex
@article{caliskan2025simcitynet,
  title   = {SimCityNet: Quantifying Geo-Cultural Bias in AI-Generated Urban Videos
             through Interpretable Scene Embeddings},
  author  = {Caliskan, Cantay and Iskakov, Abylay and Li, Yuanzhu and McCollum, Brendan and Ren, Yi},
  journal = {SSRN Electronic Journal},
  year    = {2025},
  doi     = {10.2139/ssrn.5369073}
}
```

To cite a specific version of the software, use the **Cite this repository** button on
GitHub (generated from `CITATION.cff`) or the version DOI on Zenodo, and report the version
from `simcitynet --version`.

Please also cite the models SimCityNet builds on when relevant: Mask2Former (Cheng et al.,
2022), DPT (Ranftl et al., 2021) and YOLOv9 (Wang et al., 2024).
